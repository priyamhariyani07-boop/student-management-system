# Student Management System

A CLI application built with Python for managing student records, tracking academic performance, and exporting reports[cite: 1].

## Features
- **Student Profiling:** Add, search, view, and delete student records[cite: 1].
- **Academic Performance:** Record subject grades and dynamically calculate average GPA[cite: 1].
- **JSON Data Persistence:** Automatically saves all student data to `students.json`[cite: 1].
- **CSV Export:** Export student summaries to `students_report.csv` for analysis in Excel or Google Sheets.

## Concepts Applied
- Object-Oriented Programming (Classes, Methods, `@classmethod` constructors)[cite: 1]
- File Operations (`json` and `csv` modules)[cite: 1]
- Data Structuring (Nested Dictionaries & Lists)[cite: 1]
- Exception & Input Handling[cite: 1]
